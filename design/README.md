# ตัวละคร tutor — ต้นแบบ (ยังไม่ได้ต่อเข้าแอป)

ไฟล์ในโฟลเดอร์นี้เป็น **ต้นแบบที่รันได้จริง** ไม่ใช่ภาพ mockup — เปิดด้วย static server แล้วกดฟังเสียงพร้อมดูปากขยับได้เลย

```bash
cd design && python3 -m http.server 5200
# แล้วเปิด http://localhost:5200/tutor-character.html
```

ต้องเปิดผ่าน `http://` ไม่ใช่ `file://` เพราะ `alt-dicebear-personas.html` ใช้ `fetch()` โหลดไฟล์ใน `db/`

## ทำไมถึงเลือกทางนี้แทนตัวละคร 3D

ของเดิมในแอปใช้ VRM/GLB ผ่าน three.js ซึ่งลองแล้วพบว่า **เบราว์เซอร์เรนเดอร์คนเหมือนจริงสู้วิดีโอไม่ได้** ยิ่งพยายามให้สมจริงยิ่งตกหุบเหว uncanny valley ส่วนตัวละครแบนสไตไลซ์ไม่ได้สัญญาว่าจะเหมือนคนจริงตั้งแต่แรก จึงทำให้ "ดีเท่าที่ควรเป็น" ได้จริง

## สิ่งที่ต้นแบบนี้พิสูจน์แล้ว

- **lip-sync ทำงานจริง** — วัดได้ 37–39 viseme ต่อประโยค ใช้ครบทั้ง 13 แบบ
- **การเคลื่อนไหว 7 ชั้นพร้อมกัน** — หายใจ · โยกหัว · กะพริบตา · ตาเหลือบ · พยักหน้า · ยักคิ้ว · ขากรรไกร (แต่ละชั้นเปิด/ปิดได้ในหน้าเพื่อดูผลทีละอย่าง)
- **ไม่ต้องใช้ Rive** — Rive แก้ปัญหา *การส่งงานจากนักอนิเมชันถึงวิศวกร* ซึ่งเป็นปัญหาของทีมใหญ่ ไม่ใช่ข้อจำกัดของเบราว์เซอร์

## กับดักที่เจอมาแล้ว — อย่าพลาดซ้ำตอนย้ายเข้าแอป

ทั้งหมดเป็นเรื่อง **ลำดับการวาด** กับ **การผูก transform** ซึ่งเป็นส่วนที่ Rive จัดการให้อัตโนมัติด้วยระบบกระดูก แต่เราต้องคิดเอง

1. **เปลือกตาเป็นสีผิว** — ถ้าวาดหลังคิ้ว มันจะทาทับคิ้วหาย ต้องวาดคิ้ว *หลัง* เปลือกตา
2. **คอ** ต้องวาด *ก่อน* เสื้อ (ไม่งั้นเป็นแท่งสีผิวพาดทับเสื้อ) แต่ต้องขยับ *ตามหัว* → แยกเป็นกลุ่ม `#headBack` ที่รับ transform ของตัวเอง
3. **คอห้ามตามหัว 100%** — โคนคอติดลำตัว ปลายบนตามหัว ใช้ **35% ของการเลื่อน + 30% ของการหมุน รอบโคนคอ** ไม่งั้นโคนคอหลุดจากคอเสื้อตอนหัวเอียง
4. **ห้าม `innerHTML` ใหม่ทุกเฟรม** — สร้าง DOM ครั้งเดียว แล้วแต่ละเฟรมแตะแค่ `transform` ของ group (`innerHTML` ของปากเปลี่ยนเฉพาะตอนเปลี่ยนรูปปาก)
5. **การขยับต้องเป็น "ไปหยุดที่ท่า → ค้าง → เปลี่ยนท่า"** ไม่ใช่แกว่ง sine ตลอดเวลา (แกว่ง sine ดูเหมือนตุ๊กตาโยกหัว) — ดูจากวิดีโอ Duolingo Video Call จริง
6. **สุ่มค่าการขยับต้องสุ่ม *ขนาด* ในช่วงที่เห็นชัดแล้วค่อยสุ่มทิศ** — สุ่ม uniform ตรง ๆ ได้ค่าใกล้ศูนย์บ่อยจนดูเหมือนไม่ขยับ

## งานที่เหลือ

1. เอาตัวละคร + ระบบ viseme + การเคลื่อนไหว ไปแทน `CartoonAvatar` ใน `app/src/components/TutorAvatar.tsx`
2. ให้เสียง Kokoro/Gemini ใช้ amplitude จาก `services/audio-bus.ts` (`getSpeechVolume()`) แทน `onboundary` — แม่นกว่า เพราะเสียงสองตัวนี้ผ่าน AnalyserNode อยู่แล้ว ส่วนเสียงระบบ (`speechSynthesis`) ไม่ผ่าน จึงยังต้องใช้ `onboundary`
3. ทำหน้า video call ทับ `FreeTalk` / `ScenePlayer`
4. **ตัดสินใจ**: ถอด `three` + `@pixiv/three-vrm` กับไฟล์ `.vrm`/`.glb` ออก หรือเก็บโหมด 3D ไว้เป็นตัวเลือกใน Settings
   (ยังไม่ได้ตัดสิน — และ repo นี้ไม่ใช่ git repo ลบแล้วกู้ไม่ได้)
